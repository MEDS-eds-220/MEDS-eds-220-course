7 Linear regression

In this lesson we will learn how to perform a simple linear regression by examining the counts, weight, and size measurements of juvenile snowshoe hares (Lepus americanus) observed at the Bonanza Creek Experimental Forest from 1998 to 2012 [1].

Learning objectives

By the end of this lesson, students will be able to:

  • Explore a dataset’s values against its metadata and document data cleaning decisions.
  • Create plots with multiple layers using matplotlib’s fig and ax.
  • Fit a simple linear regression with statsmodels using a formula.
  • Interpret the intercept, slope and \(R^2\) of a linear regression model.
  • Use residuals to assess whether a linear model is a good description of the data.

About the data

Size measurements, sex, and age of snowshoe hares were collected and made available by Dr. Knut Kielland and colleagues at the Bonanza Creek Experimental Forest Long Term Ecological Research (LTER) site located approximately 20 km southwest of Fairbanks, Alaska, USA. The data contains 3380 observations (captures) of snowshoe hares obtained by capture-recapture studies conducted yearly from 1998 to 2012 in three sampling sites: Bonanza Riparian, Bonanza Mature and Bonanza Black Spruce.

Examining hares’ age data

From the data’s info() display we can see that the age column has 1269 non-NA rows. In this example we are interested in working with data from juvenile hares exclusively. So we will:

  1. Examine the values in the age column
  2. Filter for observations in which age is ‘adult’ or ‘juvenile’
  3. Investigate the age distributions across time

From the dataset’s metadata we know there are three allowed values in the age column:

  • ‘a’ for ‘adult’,
  • ‘j’ for ‘juvenile’, and
  • ‘m’ for ‘mortality’.

Since the actual data has values that are not included in the metadata, this is the time to make a decision and document it. Since the metadata states that ‘a’ indicates adult and ‘j’ indicates juvenile, we will only keep observations that have ‘a’ or ‘j’ (either capitalized or not) as part of the age value.

# Update age values to juvenile and adult for observations where 'a' and 'j' are included
obs.loc[obs['age'].str.contains('j', case=False, na=False), 'age'] = 'juvenile'
obs.loc[obs['age'].str.contains('a', case=False, na=False), 'age'] = 'adult'

# Filter for confirmed observations of juvenile and adult hares
obs_juv_adult = obs[obs['age'].isin(['juvenile', 'adult'])].copy()
print("Number of juvenile and adult hare observations (captures):", len(obs_juv_adult))
Number of juvenile and adult hare observations (captures): 1155

None of the observations from 1998 have a valid age, so from here on our data starts in 1999.

Plotting with matplotlib

matplotlib’s fig and ax

Later in this lesson we will want to plot our linear model together with our data. To make visualizations where we add different layers to a graph and customize it, we will use the matplotlib Python library for creating visualizations. We can interact with matplotlib via its pyplot interface, which we imported at the top of the notebook.

Matplotlib graphs the data in a figure which can have one or more axes. The axes is only the area specified by the \(x\) axis and \(y\) axis and what is plotted in it, while the figure can include multiple axes in it.

To create a new blank figure:

  1. Initialize a new figure and axes by calling pyplot’s subplots() function
  2. Display the figure using plt.show():
# Initialize empty figure (fig) and axis (ax)
fig, ax = plt.subplots()

# Display figure
plt.show()

Notice that plt.subplots() is a function that returns two objects, when we call it, we get a figure fig with a single empty axis ax. We can think of this step as setting a new blank canvas on which we will paint upon.

Adding a layer

When using matplotlib, it can be useful to think of creating a plot as adding layers to an axis. The general syntax to plot data from a data frame df onto an axis is:

# Initialize empty figure and axis
fig, ax = plt.subplots()

# Plot df on the ax axis
df.plot(ax=ax,  # Add plot to axis
        ...)    # Other arguments for plot function

# Display figure
plt.show()

For example, let’s add a scatter plot of the hind foot length and weight of all the juvenile and adult captures to our axis:

# Initialize empty figure and axis
fig, ax = plt.subplots()

# Add scatter plot of hares' data to our figure's axis
obs_juv_adult.plot(kind='scatter', x='hindft', y='weight', ax=ax)

# Display figure
plt.show()

Customization

Matplotlib allows for a lot of customization. Some of it can be done directly in the plot() method for the data frame (like we’ve done when plotting data using pandas), while other is done by updating attributes of the ax axis. The following diagram shows some examples of elements in the axis that can be updated.

For example, we can update the title and axis labels of our previous plot like this:

Linear regression

For our analysis we want to investigate possible relations between hind foot length and weight for juvenile hares. Let’s take a look at our target data:

# Subset juvenile hares and drop rows missing hind foot or weight measurements
juveniles_weight_hindft = obs_juv_adult[obs_juv_adult['age'] == 'juvenile'].dropna(subset=['hindft', 'weight'])

print("Number of juvenile hare captures with hind foot and weight measurements:", len(juveniles_weight_hindft))
juveniles_weight_hindft.plot.scatter(x='hindft', y='weight', alpha=0.5)
Number of juvenile hare captures with hind foot and weight measurements: 265

Remember from our bar plot that the number of captures changed a lot from year to year: our regression combines juveniles from all years, and almost a third of them (79 of 265) were captured in 1999.

We can see there seems to be a linear trend between the weight and hind foot length variables, though as the hind foot length increases the variability does too.

Let’s investigate whether a linear model is an adequate way to describe this data. To do this we will use the statsmodels library, which has tools for fitting statistical models. At the top of the notebook we imported it as smf.

Remember that in statistical notation the linear regression model is

\[y = \beta_0 + \beta_1 x + \epsilon,\]

where \(x\) = the predictor variable, \(y\) is the response variable, and \(\epsilon \sim Normal(0, \sigma)\). Once we estimate the coefficients from the data, the equation of the fitted line is

\[\hat{y} = \hat\beta_0 + \hat\beta_1 x, \]

where

  • \(\hat{y}\) = the estimated value of the response \(y\) at \(x\) from the linear model
  • \(\hat\beta_0\) = the \(y\)-intercept of the linear model, this is interpreted as the estimated average value of the response when the predictor is \(x=0\)
  • \(\hat\beta_1\) = the slope of the linear model, this is the estimated difference in the response \(\hat{y}\) per unit of the predictor \(x\).

If you need a refresher about how a linear regression works, click here for a great resource.

To fit the model we use the ols() function, short for ordinary least squares, the method that finds the line that minimizes the sum of the squared vertical distances between the data points and the line. It takes two arguments:

  • a formula of the form 'response ~ predictor', a string that we can read as “response explained by predictor”. The names in the formula are the names of the columns in our data frame.
  • data: the data frame with those columns.

ols() sets up the model, and calling fit() on it estimates the coefficients:

# Fit model: weight explained by hind foot length
model = smf.ols('weight ~ hindft', data=juveniles_weight_hindft).fit()

The estimated coefficients are stored in the model’s params attribute, a pandas.Series whose index has the names of the coefficients:

model.params
Intercept   -352.771986
hindft        10.092240
dtype: float64

The Intercept value is \(\hat\beta_0\) and the hindft value is \(\hat\beta_1\), the slope for the hind foot length. Let’s save them in variables to use them later:

# Retrieve intercept and slope
intercept = model.params['Intercept']
print("y-intercept:", intercept)

slope = model.params['hindft']
print("Slope:", slope)
y-intercept: -352.77198564640645
Slope: 10.092239638623006

We can also look at the coefficient of determination, \(R^2\). This is between 0 and 1, with \(R^2=1\) describing a perfect fit of the model to the data. The \(R^2\) value is interpreted as the proportion of variance in the response \(y\) that is explained by the least squares line with the predictor \(x\).

This value is stored in the model’s rsquared attribute:

print("R^2:", model.rsquared)
R^2: 0.3871164783665738

A reasonable next step would be to plot our linear model together with our data. To do this, we need to add two layers to the same graph: the data points and the regression line.

To draw the line we use the axis’s plot() method, ax.plot(x_values, y_values), which connects the points given by the lists of \(x\) and \(y\) values. A straight line only needs two points, so we use the smallest and largest hind foot lengths and calculate their estimated weights with the equation of the linear model, \(\hat{y} = \hat\beta_0 + \hat\beta_1 x\):

# Smallest and largest hind foot lengths
x_start = juveniles_weight_hindft['hindft'].min()
x_end = juveniles_weight_hindft['hindft'].max()

# Initialize empty figure and axis
fig, ax = plt.subplots()

# Add data to axis
juveniles_weight_hindft.plot(kind='scatter', 
                             x='hindft', 
                             y='weight', 
                             alpha=0.5,     # Adjust transparency
                             ax=ax)         # Add plot to axis

# Add regression line to axis
ax.plot([x_start, x_end], 
        [intercept + slope*x_start, intercept + slope*x_end],
        color='darkred')

# Update axis
ax.set_title('Hind foot length and weight of juvenile snowshoe hares')
ax.set_xlabel('Hind foot length (mm)')
ax.set_ylabel('Weight (g)')

# Display figure
plt.show()

Checking the residuals

\(R^2\) tells us how much of the variation the model explains, but not whether a straight line is the right shape for the data. One check for this is looking at the residuals. A residual is the difference between an observed value and the value predicted by the model:

\[e_i = y_i - \hat{y}_i.\]

The residuals are the \(\epsilon\) in our model equation, so the model assumes they are normally distributed around 0, with the same standard deviation \(\sigma\) for every value of the predictor. statsmodels calculates the residuals for us and stores them in the model’s resid attribute.

Let’s start with a histogram to see their distribution:

model.resid.plot(kind='hist', 
                 bins=30, 
                 title='Distribution of residuals', 
                 xlabel='Residual (g)')

The residuals are centered near 0 and roughly bell-shaped, but with a long tail of negative residuals: some hares weigh much less than the line predicts. Let’s see where these residuals come from.

If a linear model describes the data well, the residuals should be scattered randomly around 0, with about the same spread for every value of \(x\). Let’s plot them against the hind foot length. Since the residuals are not a column of our data frame, we plot them with the axis’s scatter() method, ax.scatter(x_values, y_values). We also add a horizontal reference line at 0 with ax.axhline():

# Initialize empty figure and axis
fig, ax = plt.subplots()

# Add residuals to axis
ax.scatter(juveniles_weight_hindft['hindft'], model.resid, alpha=0.5)

# Add reference line at 0
ax.axhline(0, color='darkred', linestyle='--')

# Update axis
ax.set_title('Residuals of the linear model')
ax.set_xlabel('Hind foot length (mm)')
ax.set_ylabel('Residual (g)')

# Display figure
plt.show()

The residuals show three patterns:

  • The spread grows with hind foot length. For short hind feet most residuals are within about 100 g of 0, while for the longest hind feet many are more than 300 g away. This is the increasing variability we noticed in the first scatter plot. It means the model’s predictions are less precise for larger juveniles.
  • The residuals are not centered on 0 everywhere. For hind feet shorter than about 100 mm most residuals are negative (the line overestimates weight), while for medium hind feet they are mostly positive (the line underestimates weight). This suggests that the relationship between hind foot length and weight is not exactly linear.
  • For longer hind feet the residuals split into two groups, one above and one below the line. This could mean that another variable also affects weight.

None of these patterns means the model is useless: the line still captures the overall trend. But they are a reminder that a single \(R^2\) value doesn’t tell the whole story, and that we should be careful when using the model to make predictions, especially for larger juveniles.

  • For longer hind feet, the residuals split into two groups. Looking at the columns in our data, which variables could explain these groups?

Wrap-up

In this lesson we fit a simple linear regression of juvenile snowshoe hare weight on hind foot length. Before modeling, we explored the data and documented how we handled the age values that didn’t match the metadata. We then used statsmodels to estimate the intercept and slope, measured the fit with \(R^2\), and plotted the fitted line with matplotlib. Finally, the residuals showed that while the line captures the overall trend, the spread grows with hind foot length and other variables may also affect weight. Fitting a model is only the first step: checking it against the data tells us how far we can trust it!
